## 1. 콜드스타트 — 게임판 번역

웹 서비스와 달리 게임은 UGC·참여 데이터가 없다. 대신 **콘텐츠 물량 자체가 콜드스타트**다.
"기능은 다 됐는데 주울 게 5종류뿐"이면 3분 만에 바닥이 보인다.

| 채울 것 | 최소 | 현재 | 왜 이 수량 |
|---|---|---|---|
| 쓰레기 종류 | 16종 | **22종** ✅ | 한 런에 수백 개를 간다. 적으면 즉시 반복으로 읽힌다 |
| **이동 패턴** | 5종 | **5종** ✅ | 🔴 숫자만 다르면 22종이어도 한 종류로 느껴진다 (실제로 겪었다) |
| 무기 | 5종 | **5종** ✅ | 후반에 다섯이 동시에 도는 그림이 이 장르의 상품 |
| 카드 | 18종 이상 | **22종** ✅ | 레벨업마다 3장씩 뽑는다. 적으면 매 런 같은 빌드가 된다 |
| 맵 · 보스 | 6맵 × 보스 | **6맵** ✅ / 보스 🟡 | 보스가 아직 HP 큰 덩어리일 뿐이다 |
| **메타(우주선 종류)** | 4~6척 | **0** 🔴 | 재방문 이유가 여기서 나온다 |
| 도트 에셋 | 위 수량만큼 | **0** 🟡 | **일정 최대 변수** |

🔴 **물량은 거의 찼는데 메타가 0이다.** 지금 상태는 "한 판은 되는데 두 판째 이유가 없는" 게임이다.
콜드스타트 관점에서 다음 한 칸은 무기도 맵도 아니고 **메타**다.

### 🟡 도트 아트가 이 프로젝트의 진짜 병목이다

기획·코드는 진행할 수 있지만 아트는 못 건너뛴다. 세 경로:

| 경로 | 비용 | 위험 |
|---|---|---|
| 사용자가 직접 | 시간 (도트는 학습곡선이 완만한 편) | 물량 22종에서 지친다 |
| 에셋 구매 (itch·Unity Asset Store) | 몇만 원 | **다른 게임과 그림이 겹친다.** 스팀에서 감점 요인 |
| 외주 | 수십만 원~ | 재미 검증 전에 쓰면 매몰비용이 기획을 왜곡한다 |

**권장 순서**: 그레이박스 검증 통과 → 구매 에셋으로 itch 데모 → 반응 좋으면 스팀용 오리지널 아트.
검증 전에 아트에 돈·시간을 넣지 않는다([[SCHEMA]] 제1원칙).

> 🔴 이 장르는 화면에 **동시에 200개**가 뜬다. 개당 퀄리티보다 **실루엣 구분**이 중요하다 —
> 아트를 고를 때 "예쁜가"가 아니라 "겹쳐도 구분되는가"로 판단할 것.

### 가짜로 채우지 않는 것

리더보드 점수, 리뷰, 플레이 통계, 위시리스트 수.
`project-planning.md` §5 그대로 — **발각 비용이 비대칭**이고, 인디 커뮤니티는 특히 빠르게 알아챈다.

## 2. 유통 — 첫 1,000명

### 경로

```
1. itch.io WebGL 데모        ← 주 경로. 클릭 즉시 플레이, 설치 마찰 0
2. GIF 시딩 (레딧·X·국내 인디 커뮤니티)
3. itch devlog 연재          ← 느리지만 누적됨
```

| 경로 | 기간 | 전제 조건 |
|---|---|---|
| itch 자체 노출 (New & Popular) | 즉시~1주 | 커버 이미지·GIF가 좋아야 한다. **썸네일이 전부다** |
| r/roguelites, r/IndieDev, r/pixelart | 즉시 | **GIF 하나로 게임이 설명돼야** 한다. 링크만 던지면 광고글 |
| X / 블루스카이 #screenshotsaturday | 즉시 | 꾸준함이 필요. 한 번으론 안 됨 |
| 국내 인디 커뮤니티 · 디스콰이엇 | 즉시 | 사이드프로젝트 이야깃거리가 있어야 함 |
| 스팀 위시리스트 | 6개월+ | itch 반응이 먼저 |

### 🔴 유통이 MVP 기능 우선순위를 바꾼다

이 세 개는 "나중에"가 아니라 **MVP 필수**다.

1. **WebGL 빌드가 돌아갈 것** — 초기부터 주기적으로 확인. 마지막에 하면 전면 수정
   🔴 이 장르는 화면에 200개가 뜬다. **WebGL 성능이 실제 위험**이다.
   `GameHud`가 아직 OnGUI인 것도 여기서 문제가 된다
2. **10초 GIF로 게임이 읽힐 것** — 무기 다섯이 동시에 터지고 파편이 쏟아지는 그림
   (`success-state.md`의 "반드시 읽혀야 하는 것 5가지")

   🔴 **메타가 스펙터클을 게이팅하지 않는다.** 게임을 파는 그림을 게임을 산 사람만 볼 수 있으면
   유통이 성립하지 않는다. **무기 5종은 전부 첫 런에서 카드로 뽑을 수 있어야 하고**,
   화면이 덮이는 그림은 메타 해금 없이 한 런 안에서 도달 가능해야 한다.
   (rev.3의 "테크트리가 특수 장비를 잠근다"를 이 이유로 폐기했다 — 2026-08-20 외부 리뷰)
3. **첫 30초 안에 루프 한 바퀴** — 튜토리얼 없이
   🔴 이 장르에서 그건 **첫 레벨업**을 뜻한다. 30초 안에 카드를 한 번 뽑아야 한다

### 경로가 막히면

itch에서 반응이 없다면 원인은 대개 둘 중 하나다.
- **썸네일/GIF 문제** → 게임은 그대로 두고 소재만 다시 만든다 (싸다)
- **재미 문제** → 브리프로 돌아가 축을 교체한다 (비싸다)

둘을 구분하려면 **플레이 시작률 vs 30초 이탈률**을 봐야 한다.
itch 통계로 전자는 보이고, 후자는 게임 안에 간단한 카운터가 필요하다 🟡 (WebGL 로컬 저장으로 충분).

## 3. 스팀

브리프에서 **스팀 관련은 전부 뒤로 미뤘다.** 순서만 적어 둔다.

```
itch 데모 반응 확보 → 스팀 다이렉트 등록($100, 1작품당) → 스토어 페이지 →
위시리스트 모으기(최소 몇 달) → 출시
```

주의할 것 두 가지:

- **스팀 페이지를 너무 일찍 열면 위시리스트가 안 모인 채 출시일이 온다.** 페이지 오픈 자체가 카드다
- **출시는 한 번뿐이다.** 재출시가 없어서, 첫 반응을 되돌릴 수 있는 곳(itch)에서 먼저 받는 이 순서가 중요하다

🔴 **이 장르는 스팀에서 특히 포화 상태다.** 뱀서 클론은 수백 개고 대부분 묻힌다.
스팀에 가려면 브리프 §8의 차별점(청소라는 동사)이 **GIF에서 즉시 읽힐 만큼** 진해져야 한다.
지금 흰 사각형 상태로는 그 판단이 불가능하다 — 아트가 유통의 전제 조건이다.
