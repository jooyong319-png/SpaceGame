# 컨셉과 게임의 간극 — "청소"를 진짜로 만들려면

> 2026-08-22. 사용자 지적: *"우주 쓰레기 청소라는 컨셉에 맞게 뭘 추가·수정할지 잘 생각해둬야 해.
> 게임성이 많이 바뀐다 할지라도. 이건 그냥 뱀서라서."*
>
> 🔴 **맞는 지적이다.** 이 문서는 그걸 인정하고 무엇을 바꿔야 하는지 적는다.

---

## 1. 지금 상태 — 정직하게

**"청소"는 껍데기다.** 몬스터를 쓰레기로 바꾸고 총을 절단날로 바꿨을 뿐,
플레이어가 하는 일은 뱀서와 **동사 단위로 같다.**

| | 뱀파이어 서바이버즈 | 살비지런 |
|---|---|---|
| 움직인다 | 피하려고 | 피하려고 |
| 무기가 자동 발사 | ✔ | ✔ |
| 적이 몰려온다 | ✔ | ✔ |
| 죽이면 경험치가 떨어진다 | ✔ | ✔ (파편) |
| 레벨업 → 카드 3장 | ✔ | ✔ |
| 영구 강화 | ✔ | ✔ (테크트리) |
| 끝에 보스 | ✔ | ✔ |

지금까지 만든 **유일한 구조적 차이**는 "무기를 2개만 갖고 계열 조합" 하나다.
그건 **뱀서의 변형**이지 다른 장르가 아니다.

### 🔴 왜 이렇게 됐나

`decisions`를 보면 2026-08-20에 **"메커니즘은 전투, 표현은 청소"**를 제2원칙으로 박았다.
그때 판단은 옳았다 — 전투를 빼면 장르가 성립하지 않으니까.

그런데 그 뒤로 **표현만 청소로 유지하고 메커니즘은 손대지 않았다.**
"표현은 청소"가 "청소는 표현일 뿐"이 되어 버렸다.

---

## 2. 청소라는 행위의 본질

무엇이 "치우는 것"을 치우는 것답게 만드는가:

1. **장소에 상태가 있다.** 더러운 방과 깨끗한 방은 다르다
2. **진행이 공간에 보인다.** 치운 자리는 눈에 띄게 달라진다
3. **끝이 있다.** 방 하나는 다 치울 수 있다
4. **놔두면 쌓인다.** 안 치운 것은 사라지지 않는다
5. **치운 것을 어딘가로 옮긴다.** 버리거나, 분류하거나, 가져간다

**지금 게임은 이 중 하나도 없다.**
쓰레기는 무한히 나오고, 부수면 사라지고, 맵은 영원히 그대로다.
그래서 "청소"가 아니라 "전투"로 읽힌다.

---

## 3. 바꿀 수 있는 것들 (변화 크기 순)

### 🔴 A. 오염도 — 승리 조건을 바꾼다 ⭐ 핵심

맵에 **오염도**를 준다.
- 살아 있는 쓰레기가 많을수록 **오른다**
- 부수면 **내려간다**
- 목표: 웨이브를 버티는 게 아니라 **오염도를 0으로 만드는 것**
- 100%가 되면 실패 — 구역을 잃는다
- 배경이 실제로 **맑아진다** (탁한 안개가 걷힌다)

**이 하나가 장르를 바꾼다.** "살아남기"가 "치우기"가 된다.
웨이브의 압박도 의미가 달라진다 — 적이 오는 게 아니라 **더러워지는 속도**다.

브리프 §8의 차별점 "끝이 있다"가 그제야 **메커니즘에 자리를 잡는다.**
지금은 그냥 웨이브 카운터일 뿐이다.

### 🔴 B. 안 치운 것은 쌓인다

지금 파편은 14초 뒤 사라진다. **놔둔 대가가 없다.**
- 파편이 안 사라지고 **남는다**
- 오래 남으면 **뭉쳐서 더 큰 쓰레기가 된다**
- 즉 게으르면 일이 늘어난다

A와 짝이다. 오염도가 있어도 방치 비용이 없으면 그냥 카운터다.

### 🟡 C. 분해 — 부수는 게 아니라 뜯는다

큰 잔해는 **부위 순서대로** 뜯어야 한다 (지금 보스가 하는 것을 일반 쓰레기로).
"죽인다"가 아니라 "해체한다"가 된다.
구현비 중간, 체감 큼.

### 🟡 D. 못 부수는 위험물 — 밀어내야 한다

방사성 폐기물 같은 건 **부술 수 없다.** 구역 밖으로 밀어내거나 처리장에 넣어야 한다.
전투가 아니라 **처리**다. 중력·견인 무기에 존재 이유가 생긴다.

### 🟡 E. 청소 등급

결과 화면이 "생존 300초"가 아니라 **"구역 청소율 87% · 등급 B"**.
같은 맵을 다시 하는 이유가 생긴다 (지금은 클리어하면 끝).

### ⚪ F. 화물칸 · 모선 귀환

적재 한계를 두고 모선에 비우러 간다.
가장 "샐비지"다운 메커니즘이지만 **rev.2에서 한 번 잘라냈다** —
뱀서의 흐름을 끊기 때문이다. 다시 넣는다면 **이유를 새로 만들어야 한다.**

## 4. 추천

**A + B + E를 묶어서 하나로.** 이게 최소 단위다.

- A 없이 B만 하면 그냥 성가신 게임
- B 없이 A만 하면 오염도가 그냥 킬 카운터
- E는 A를 화면에 보이게 만드는 값싼 마무리

C·D는 그다음. F는 보류.

### ⚠️ 대가

- **지금까지 잡은 밸런스가 전부 무효가 된다.** 웨이브·HP·보스가 "살아남기" 기준으로 맞춰져 있다
- 친구 테스트 빌드가 나가 있다. 피드백이 오면 그건 **옛 게임에 대한 것**이 된다
- 시뮬레이터도 다시 써야 한다 (지금은 생존·파편을 잰다)

### 🔴 그래서 순서 제안

1. **친구 피드백을 먼저 받는다.** 이미 나가 있으니 그건 공짜로 얻는 정보다
2. 그 사이 **A를 작게 프로토타입**한다 — 오염도 바 + 배경 흐림 + 승리 조건.
   맵 1에서만, 밸런스는 대충
3. 사장님이 직접 해보고 **"이게 청소 같은가"** 판단
4. 그렇다면 B·E를 붙이고 전체 밸런스를 다시 잡는다

**한 판 해보면 5분 만에 알 수 있는 것**을 문서로 더 논하지 않는다.

## 5. 하지 말아야 할 것

- **동사를 또 갈아엎기.** rev.1~3에서 세 번 했고 전부 플레이 없이 했다.
  이번엔 **A를 붙여보고 판단**한다. 뱀서 기반은 유지한다
- **청소 요소를 잔뜩 넣기.** A 하나로 장르가 바뀌는지 먼저 본다
- **전투를 빼기.** [[SCHEMA]] 제2원칙 — 전투 0은 이 장르가 성립하지 않는다.
  A는 전투를 **없애는 게 아니라 목적을 바꾼다**

# rev.6 방향 — 모선 루프 (2026-08-22 결정)

> 사용자 결정: **장소 + 운반을 둘 다.** 위 3·4번 선택지를 합친 것.
>
> *"가운데를 기지같이 해두고 쓰레기를 많이 수집할수록 우주선이 점점 무거워져서 디버프가 있는 거지.
> 그걸 기지로 돌아가서 넣으면 넣은 걸로 레벨업도 하고. 무기도 기지에서 재화 써서 리롤.
> 기지도 영구강화로 강화."*

## 🔴 왜 이게 게임성인가

뱀서에서 플레이어가 하는 결정은 **둘뿐**이다 — 어디 서 있을까, 어떤 카드를 고를까.
나머지는 자동이다. 그래서 후반이 자동조종이 된다.

이 설계는 **세 번째 결정**을 넣는다: **더 모을까, 지금 돌아갈까.**

- 파편은 자동으로 경험치가 되지 않는다. **기지에 입금해야** 레벨이 오른다
- 많이 들수록 **무거워진다** — 느려지고 위험해진다
- 즉 **욕심이 곧 위험**이고, 그 저울질이 매 순간 돌아간다

뱀서에 이 층이 없다. 이게 "그냥 뱀서"를 벗어나는 지점이다.

## 루프

```
기지에서 출발
   └─ 나가서 청소 → 파편이 쌓인다 → 무거워진다 (느려짐 · 회피 어려워짐)
        · 계속 모을까?  더 벌지만 더 위험
        · 지금 돌아갈까? 안전하지만 덜 벌어
   └─ 기지를 지나가면 **입금** → 그만큼 레벨업 → 카드
   └─ 다시 나간다
        ...
   최종 웨이브 → 보스가 **기지를 포위한다** → 입금이 막힌다
```

## 구성 요소

| 요소 | 하는 일 |
|---|---|
| **화물 무게** | 파편 수에 비례해 속도·가속 저하. 시각적으로도 배가 무거워 보인다 |
| **입금** | 기지 근처를 **지나가기만 하면** 자동. 메뉴 없음 — 흐름을 끊지 않는다 |
| **레벨업** | 입금한 양으로만 오른다 |
| **리롤** | 기지에서 재화를 써서 **두 번째 무기를 바꾼다** |
| **기지 강화** | 영구 강화(테크트리)에 기지 항목 — 입금 반경, 입금 보너스, 적재 한계 |
| **보스** | 기지를 포위 → 입금 차단 |

## ⚠️ 위험과 대응

| 위험 | 대응 |
|---|---|
| **흐름이 끊긴다** (rev.2에서 이걸로 잘라냄) | 메뉴 없이 **지나가면 입금**. 귀환 길 자체를 긴장 구간으로 |
| **죽으면 다 잃는다 → 다시 안 함** | 죽을 때 화물을 **그 자리에 흘린다**. 회수 가능 |
| **왕복이 지루해진다** | 무게가 클수록 입금 **보너스**. 아슬아슬하게 버티다 가는 게 이득 |
| 보스와 기지 위치 충돌 | 충돌이 아니라 **소재로 쓴다** — 보스가 기지를 포위 |

## 프로토타입 범위 (이것만 먼저)

🔴 **한 판 해보고 판단할 수 있는 최소한만.** 밸런스는 대충.

1. 화물 무게 → 속도 저하
2. 기지 지나가면 입금 → 그만큼 레벨업
3. 화면에 **적재량 / 무게 / 입금하면 오를 레벨** 표시
4. 죽으면 화물 흘리기

리롤·기지 강화·보스 포위는 **1~4가 재미있다고 판단된 뒤에.**

## ⚠️ 대가

- 지금 밸런스가 **전부 무효**가 된다 (XP 곡선이 근본부터 달라진다)
- 시뮬레이터의 봇도 다시 짜야 한다 (지금 봇은 귀환을 모른다)
- 친구 테스트 빌드는 **옛 게임**이 된다 — 그 피드백은 조작감·가독성 부분만 유효
