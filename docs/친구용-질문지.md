# 친구에게 그대로 복사해 보낼 것

> 이 파일은 **친구가 읽는 글**이다. 개발 쪽 의도와 판단 기준은 `playtest-brief.md`에 따로 있다.
> 여기에 "왜 이걸 묻는가"를 적지 않는다 — 의도를 알면 답이 그쪽으로 휜다.

---

## 1) 게임 보낼 때 (링크와 함께)

```
우주 쓰레기 청소하는 게임 만들고 있는데 한 판만 해볼래?
브라우저에서 바로 돌아가. 5~10분이면 돼.

[링크]

⚠️ 그림은 아직 임시야. 네모랑 도형으로 대충 해둔 거라 그건 빼고 봐줘.

조작
· 좌클릭 꾹 누르면 커서 쪽으로 이동 (떼면 미끄러짐)
· Shift = 순간 가속
· 무기는 알아서 나가니까 위치만 잡으면 돼
· 레벨 오르면 카드 3장 중 1장 고르는 화면 나옴
```

---

## 2) 다 하고 나서 보낼 것

```
해줘서 고마워! 딱 6개만 물어볼게. 짧게 답해도 돼.

1. 시작하고 처음 30초, 뭘 해야 하는지 바로 알겠던가?
   (헤맸으면 어디서 헤맸는지)

2. 무기 고르는 화면 나왔을 때 —
   고민하고 골랐어, 아니면 그냥 아무거나 눌렀어?
   뭘 골랐는지 기억나?

3. 죽었어? 몇 분쯤에?
   아니면 안 죽었는데 그냥 껐어?

4. 한 판 더 하고 싶었어?  →  실제로 했어?

5. 제일 재밌었던 순간 하나 / 제일 별로였던 순간 하나

6. 뭐가 제일 헷갈렸어? (화면에서 뭐가 뭔지 모르겠던 거)
```

---

## 3) 답을 여러 명한테 받을 때

같은 말이 **두 번** 나오면 그건 사실이다. 한 명만 한 말은 취향일 수 있다.

🔴 **한 번에 다 보내지 말 것.** 2명 먼저 → 명백한 문제 고치고 → 나머지.
안 그러면 같은 버그를 5명이 겪고 피드백 5개가 전부 그 얘기가 된다.
