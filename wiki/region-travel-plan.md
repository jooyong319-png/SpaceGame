# 지역 이동 설계 (rev.10 ⬜ 미구현)

> 사용자: *"기지가 여러 지역(맵)을 돌아다니며 쓰레기를 수집하는 거야."*

이 문서는 **구현 전에 정한 것**이다. 코드를 쓰기 전에 판단 근거를 남긴다.

---

## 왜 필요한가

rev.10에는 **이기는 방법이 없다.** 기지 연료가 0이면 지지만, 아무리 잘해도 끝나지 않는다.
rev.8에서 이미 겪은 문제의 거울상이다 — 그때는 지는 방법이 없었다.

지역 이동이 승리 조건을 만든다: **N개 지역을 통과하면 이긴다.**

## 🔴 왜 '가동 게이지'가 아니라 '지역 이동'인가

rev.8의 스페이스바 게이지는 **밖에서 덧붙인 규칙**이었다.
왜 기지 안에서 스페이스바를 눌러야 하는지 이야기가 설명하지 못한다.

지역 이동은 다르다 — **기지가 돌아다니는 배**라는 설정이 곧 규칙이다.
연료를 채워서 다음 지역으로 간다. 설명이 필요 없다.

## 루프

```
지역 도착
  └─ 밭을 캔다 → 화물이 쌓인다 → 무거워진다
  └─ 기지에 입금 → 기지 연료 회복 + 레벨업(보상 N장)
  └─ 기지 연료가 **출발선**을 넘으면 → 다음 지역으로 갈 수 있다
       · 지금 갈까?  안전하지만 덜 벌어
       · 더 캘까?    연료는 계속 닳는다
  └─ 다음 지역은 더 빨리 닳는다
```

## 🔴 핵심 설계 판단: 출발은 **선택**이어야 한다

가장 쉬운 구현은 "연료가 가득 차면 자동으로 출발"이지만 그러면 결정이 없다.

**출발 비용**을 두고 플레이어가 고르게 한다:

- 다음 지역으로 가려면 기지 연료를 **일정량 쓴다** (`travelFuelCost`)
- 즉 **연료가 곧 여비**다. 지금 가면 남은 연료가 적은 채로 시작하고,
  더 캐고 가면 여유롭게 시작하지만 그동안 연료가 계속 닳는다
- 이 저울이 rev.6의 "더 모을까 / 지금 돌아갈까"를 **지역 단위로 한 겹 더** 쌓는다

## 무엇을 지역마다 바꾸나

| 값 | 어떻게 |
|---|---|
| `baseDrainPerSecond` | 🔴 **주 난이도 손잡이.** 깊을수록 빨리 닳는다 |
| 밭 밀도 · 가치 | 깊을수록 좋다 — 위험에 값이 붙어야 간다 |
| 로봇 비율 · 등급 | 깊을수록 세다 |
| 맵 크기 | 깊을수록 넓다 (왕복이 길어진다 = 연료 압박) |

## ⚠️ 하지 말 것

- **지역 선택 메뉴를 만들지 말 것.** rev.2에서 만들었다가 잘라냈다.
  고를 게 없으면 메뉴는 확인 버튼일 뿐이다.
  선택은 *"언제 갈까"* 하나로 충분하다
- **지역을 8개씩 만들지 말 것.** 3~5개로 20분 한 판.
  itch 브라우저 플레이어는 10분이면 닫는다

  ⚠️ **2026-08-22 현재 6개다** (기지 궤도 → 폐선 항로 → 잔해장 → 파괴된 정거장 → 심연 → 균열).
  rev.4 시절 맵을 그대로 쓰고 있어서 그렇다. 한 지역이 몇 분인지 재 본 뒤,
  길면 **지역을 줄이지 말고 지역당 시간을 줄이는** 쪽이 낫다 —
  지역마다 감소율이 다르므로 개수를 줄이면 난이도 곡선이 통째로 뭉개진다
- 지역마다 새 컨텐츠를 만들지 말 것. **같은 밭·같은 로봇의 밀도와 세기만** 바꾼다.
  컨텐츠가 갈라지면 밸런스를 지역 수만큼 따로 잡아야 한다

## 구현 상태 (2026-08-22)

✅ 1~4 구현 완료 · ⬜ 5는 미구현

1. `StageDef`에 `travelFuelCost` 추가
2. 기지에서 **출발 가능 조건**(연료 > 비용)일 때 HUD에 "다음 지역으로 [출발]" 표시
3. 출발 → 연료 차감 → `MapIndex++` → `field.Build(다음 지역)` → 화물·레벨은 **유지**
4. 마지막 지역을 넘기면 **승리**
5. ⬜ 지역 사이에 짧은 정산 화면 (몇 초, 건너뛰기 가능) — **아직 없다**

🔴 **3번의 "화물·레벨 유지"가 중요하다.** 지역마다 초기화하면
지역 이동이 이득이 아니라 손해가 되어 아무도 안 간다.
