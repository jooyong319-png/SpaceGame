# 최종 지역 승리 조건 — 선택지 (⬜ 사장님 판단 대기)

> **rev.10의 마지막 빈칸이다.** 지금은 마지막 지역(균열)에 도착하면 그냥 버틴다.
> 이기는 방법이 없으므로 **끝나지 않는 게임**이다.
>
> rev.8에서 정확히 같은 문제를 겪었다(그때는 지는 방법이 없었다).
> 그러니 이건 취향 문제가 아니라 **반드시 메워야 하는 구멍**이다.

이 문서는 **고르기만 하면 되도록** 정리한 것이다. 셋 중 하나를 말씀해 주시면 바로 구현한다.

---

## A. 최종 보스 — 기지를 포위한다

마지막 지역에 도착하면 거대 잔해가 **기지를 둘러싸고 입금을 막는다.**
부위를 다 뜯어내면 승리.

| | |
|---|---|
| ✅ 좋은 점 | 이미 `BossBehaviour`·`BossDef`가 있다. **가장 적게 만들고 가장 큰 사건** |
| ✅ | "입금을 막는다"가 rev.10의 규칙을 그대로 쓴다 — 새 규칙을 안 배워도 된다 |
| ✅ | 기지 연료가 계속 닳으므로 **시간 압박이 저절로 생긴다.** 오래 끌면 진다 |
| ⚠️ 위험 | 보스가 지금 rev.4 시절 설계다. 쓰레기가 밭이 된 지금 어울릴지 미지수 |
| ⚠️ | 드릴은 단일 표적이라 보스와 궁합이 좋다 — 반대로 장판형은 불리해진다 |

🔴 **내 추천은 이것이다.** 있는 것을 쓰고, 기존 규칙 위에 얹히고,
"마지막 판"이라는 감각이 가장 확실하다.

---

## B. 목표량 — 정해진 양을 캐서 채운다

최종 지역에서 **화물 N개를 입금하면** 승리. 화면에 진행 막대.

| | |
|---|---|
| ✅ | 파밍 게임의 결말로 자연스럽다 — 하던 걸 계속 하면 이긴다 |
| ✅ | 구현이 가장 싸다. 카운터 하나와 막대 하나 |
| ⚠️ | **새 사건이 없다.** 마지막 지역이 그냥 "더 오래 하는 지역"이 된다 |
| ⚠️ | 기지 연료 감소와 목표량이 **같은 방향**이라 저울질이 안 생긴다 |

---

## C. 버티기 — 정해진 시간을 살아남는다

최종 지역에서 **N분 버티면** 승리. 시간이 갈수록 로봇이 거세진다.

| | |
|---|---|
| ✅ | 뱀서의 결말 방식이라 익숙하다 |
| ⚠️ | 🔴 **이 게임의 원칙과 정면으로 어긋난다.** rev.9에서 뱀서를 벗어난 지점이
  *"가만히 있으면 진다"*였는데, 버티기는 **가만히 있는 걸 보상**한다 |
| ⚠️ | 기지 연료가 닳으므로 실제로는 계속 캐야 하지만, **규칙이 그렇게 말하지 않는다** |

🔴 **권하지 않는다.** 이기는 방법이 게임의 원칙과 반대 방향을 가리키면
플레이어는 규칙을 오해한 채 플레이하게 된다.
