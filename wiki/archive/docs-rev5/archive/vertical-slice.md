| 항목 | 내용 |
|---|---|
| **층** | 1층 하나. 하강 없음 |

| **🔴 커서 조준** | 팔이 "가장 가까운 것"이 아니라 **커서 방향에 가까운 것**을 우선 잡는다 |

| **🔴 연료** | **시간당 기본 소모 + 추진 시 추가 소모** (정지 무한 런 버그 제거) |
| **쓰레기** | HP를 가진다. 부서지면 **파편**이 나온다 |
| **파편** | 배로 자동 흡수 = 크레딧 + 경험치 |
| **카드** | **5장만.** 팔 +1 / 팔 길이 + / 채굴 속도 + / 흡수 반경 + / 최대 연료 + |
| **보스** | **1종, 부위 3개.** 할당량 채우면 등장. 깨면 런 종료 |
| **종료** | 연료 0 또는 보스 격파 → 결과 화면 → 다시 |

## 🔴 확인할 것 딱 세 가지

플레이하면서 이것만 본다. 다른 게 눈에 밟혀도 적어두고 넘어간다.

1. **깎는 게 손맛이 있는가** — 붙었다 빠졌다 하는 미세 조작이 생기는가,
   아니면 적당한 자리에 놓고 방치하게 되는가
2. **커서가 이중 결정이 되는가** — "어디로 갈까"와 "뭘 깎을까"가 한 손가락에 겹치는 감각이 있는가
3. **팔이 2개→5개가 될 때 화면이 달라지는가** — 카드로 팔을 늘렸을 때 눈에 띄게 요란해지는가

### 판정

- 1번이 아니오 → **거리-속도 곡선부터 만진다.** 그래도 아니오면 채굴이라는 동사 자체를 재고
- 2번이 아니오 → 커서 조준의 가중치·시각 피드백(어느 팔이 뭘 잡았는지)을 손본다
- 3번이 아니오 → 팔의 시각 표현이 문제다. 개수가 아니라 **보이는 방식**을 고친다

## 작업 순서

1. `JunkPiece` — HP + 접촉 피해 (지금은 rev.2의 끌어당김 방식)
