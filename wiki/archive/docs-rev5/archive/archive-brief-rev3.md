## 0. 한 줄

**우주 쓰레기를 깎아 파편을 모으며, 스스로 정한 깊이까지 내려가는 로그라이트.**

- 장르: 2D 픽셀아트 · 뱀서라이크 계열 **채굴형** 로그라이트
- 플랫폼: PC(Windows) · 웹(WebGL) 데모 · 엔진 **Unity 6.3 LTS (URP 2D)**
- 조작: 좌클릭 홀드 = 이동 · Shift/우클릭 = 대시 · Space = 하강
- 임시 제목: **SALVAGE RUN / 살비지런** 🟡 공개 전 확정

---

## 1. 핵심 루프

```
격납고(테크트리 구매)
   └─ 출항 ─→ 1층
        층 안: 쓰레기를 깎는다 → 파편이 나온다 → 흡수 = 크레딧 + 경험치
                레벨업 → 카드 3장 중 1장 (빌드가 자란다)
                할당량 도달 → 보스 등장 → 해체 → 아래층 문이 열린다
                ▼ 하강 선택 (안전 / 급강하 / 붕괴) → 다음 층
        연료 0 → 자동 귀환 → 정산 → 격납고
```

한 런 목표: **3~6분** (층당 40~70초 × 도달 깊이)

### 🔴 이 게임의 세 가지 결정

1. **어떤 카드를 고를까** — 런 안에서 빌드를 만든다
2. **더 긁을까, 내려갈까** — 연료가 저울이다
3. **얼마나 무모하게 내려갈까** — 하강 선택지가 곧 난이도

모든 기능은 **"이 세 결정을 더 선명하게 만드는가"**로 판단한다.

## 2. 🔴 뱀서라이크와 다른 점 (차별점)

이 장르는 포화 상태다. 아래 셋이 우리의 전부이고, 이게 얇아지면 클론이 된다.

| | 뱀서류 | 살비지런 |
|---|---|---|
| 난이도 | 시간이 지나면 **자동으로** 오른다 | 🔴 **플레이어가 ▼를 눌러야** 오른다 |
| 시간 | 그냥 흐른다 | **연료가 시계다.** 안 움직이면 시간이 안 간다 |
| 적 | 쫓아온다. 죽인다 | **흘러간다. 깎아서 캔다.** 닿으면 내가 손해 |
| 끝 | 없다 | **6층 클리어 = 엔딩** (그 뒤 무한) |

> "끝이 있는 뱀서류"라는 것 자체가 판매 포인트다 — 장르가 포화라서 오히려.

---

## 3. 채굴 — 닿으면 안 된다

**쓰레기는 먹는 게 아니라 깎는 것이다.**

| 요소 | 규칙 |
|---|---|
| 쓰레기 | HP를 가진다. 도구가 원거리에서 깎는다 |
| 파편 | HP가 0이 되면 터져나온다. **이게 실제 수집 대상** |
| 파편 흡수 | 배의 기본 능력. 자동으로 끌려온다 (반경은 카드로) |
| 🔴 접촉 | **쓰레기 본체에 배가 닿으면 연료가 깎인다** |
| 위험물 | 닿으면 특히 아픈 쓰레기. 붉은 테두리로 상시 표시 |
| 보스 | **HP가 아주 큰 쓰레기.** 같은 메커니즘, 규모만 다르다 |

> 🔴 이 규칙이 조작을 만든다 — **거리 유지가 플레이의 핵심**이 된다.
> 붙으면 손해, 멀면 못 깎는다. 마우스 홀드 이동이 여기서 의미를 갖는다.

---

## 4. 장비 — 팔 + 특수 하나

**기본: 팔 2개.** 배에 달려 자동으로 가까운 쓰레기를 붙잡고 깎는다.
카드로 **팔 개수 / 팔 길이 / 채굴 속도**가 는다. 후반엔 팔 여섯이 사방을 뜯는다.

**특수 장비 1종** — 첫 레벨업 카드 3장이 정한다. 런당 하나뿐이다.

| 장비 | 성격 |
|---|---|
| 집중 빔 | 하나를 아주 빠르게. 대형·보스에 강하다 |
| 그물 발사기 | 커서 방향에 범위 전개, 안의 것을 한꺼번에 (광역 일격) |
| 회수 드론 | 팔과 별개로 자율 비행하며 깎는다 |

🟡 **자석 그리퍼는 보류.** 파편 흡수가 기본 능력이 되면서 역할이 겹쳤다.

---

## 5. 층과 하강 — 난이도를 내가 고른다

**1층에서 시작해 6층까지 순차로 내려간다.** 지역 선택 메뉴는 없다.
층마다 유입·가치·위험·워프 비용이 커진다.

### 하강 선택지 (▼를 누를 때마다)

| 선택 | 워프 비용 | 다음 층에 붙는 것 |
|---|---|---|
| **안전 하강** | 기본 | 없음 |
| **급강하** | ×1.5 | 카드 1장 즉시 |
| **붕괴 하강** | 기본 | 위험물 ×2 · 유입 ×1.4 · **가치 ×1.8** · 체류 과열 ×1.5 |

### 체류 과열

한 층에 머무는 시간에 비례해 연료 소모가 빨라진다.
눌러앉기를 막고, 연료 회수 빌드가 런을 무한히 늘리는 것을 **구조적으로** 차단한다.

## 6. 엔딩

- **6층 보스 격파 = 엔딩**
- 🔴 **전 층을 붕괴 하강으로만 내려와 클리어 = 진 엔딩**
- 엔딩 이후 **7층+ 무한 하강** (기록 경신)

## 7. 진행 3층 구조

| 층 | 자원 | 리셋 | 역할 |
|---|---|---|---|
| **런** | 카드 | 런 종료 시 | 이번 판의 빌드 |
| **회차** | 크레딧 → 테크트리 | **환생 시** | 런 단위 성장 |
| **영구** | 환생 보너스 | 없음 | **난이도 완화** |

### 🔴 환생 = 난이도 슬라이더

**환생 없이는 거의 못 깨는 난이도로 만든다.** 언제든 환생할 수 있고,
환생하면 크레딧과 테크트리가 리셋되는 대신 **누적 성과에 비례한 보너스**를 받는다.

보너스는 **파워가 아니라 완화**로 준다 — 시작 연료 +, 위험물 피해 -, 워프 비용 -,
첫 카드 선택지 +1, 팔 1개 추가 시작.

이렇게 하면:
- 잘하는 사람 → 환생 적게 하고 깬다 → **환생 0회 클리어가 훈장**
- 막히는 사람 → 환생 반복 → 조금씩 쉬워져 **결국 깬다**

즉 **난이도 조절을 게임 안에 녹인 것**이다. 옵션에서 "쉬움"을 고르는 것보다 자존심이 덜 상하고,
진 엔딩과 맞물려 환생 횟수가 그대로 성적표가 된다.

## 8. 경험치

**쓰레기(파편)가 곧 경험치다.** 가치가 클수록 경험치도 크다 →
깊은 층일수록 레벨이 빨리 오른다 = 후반 도파민이 구조적으로 나온다.

---

## 9. 설계 원칙

1. **거리 유지가 조작의 핵심이다.** 이걸 흐리는 건 넣지 않는다
2. **한 런 3~6분.** 층당 40~70초
3. **버튼을 안 누르면 연료를 쓰지 않는다** — 생각하는 시간에 벌을 주지 않는다
4. **팔과 장비는 자동으로 작동한다.** 조작 부담을 늘려 손맛을 만들지 않는다
5. **그레이박스 먼저, 도트는 나중**
6. **원칙은 코드로 강제한다.** 밸런스는 `GameContent`/`RunConfig` 에셋 한 곳에만

## 10. MVP 범위

### 넣는다
- 팔 채굴 + 특수 장비 3종 · 쓰레기 HP/파편/접촉 피해

- **적 AI / 전투** — 보스도 '해체'지 전투가 아니다. 공격·피격·체력 개념을 넣지 않는다

- 스팀 도전과제·클라우드 (스팀 페이지 여는 시점까지)
