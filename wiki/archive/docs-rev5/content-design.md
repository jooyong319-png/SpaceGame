## 0. 뼈대 — 한 규칙으로 전부 굴린다

**모든 것이 "HP를 깎으면 파편이 나온다"로 통일돼 있다.**

| 대상 | HP | 나오는 것 |
|---|---|---|
| 잡몹(미세 파편) | 1 | 파편 1 |
| 보통 쓰레기 | 3~9 | 파편 2~3 |
| 큰 잔해 | 14~28 | 파편 4~6 |
| **보스** | 아주 큼 | 부위마다 대량 |

보스가 별도 시스템이 아니다. **규모만 다른 같은 것**이고 코드도 하나다.
새 콘텐츠는 "HP가 얼마고 파편이 몇 개인가"만 정하면 된다.

## 1. 쓰레기 22종 — 종류를 가르는 건 이동 패턴이다

숫자만 다르면 종류가 아무리 많아도 **한 종류로 느껴진다.**
2026-08-20에 실제로 그랬다 — 16종이 전부 같은 방식으로 움직여서 하나처럼 느껴졌다.

### 다섯 가지 패턴

| 패턴 | 플레이어가 느끼는 것 |
|---|---|
| **Chase** | 계속 따라붙는다. 뿌리치려면 속도가 필요 |
| **Drift** | 피하면 그만. 하지만 무리로 오면 벽이 된다 |
| **Zigzag** | 예측이 어렵다. 스치기 쉽다 |
| **Charger** | 멈칫할 때 방심하면 박는다 |
| **Orbiter** | 포위당하는 느낌. 도망칠 방향이 좁아진다 |

같은 HP·속도라도 **산소 탱크(Drift·느림)** 는 피하면 그만이고,
**과열 전지(Charger·돌진)** 는 방심하면 박는다. **상황이 늘어난 것**이지 숫자가 늘어난 게 아니다.

### 잡몹이 반드시 있어야 한다

**미세 파편** — HP 1, 빠름, 5마리씩 떼로. 닿는 즉시 터진다.
이게 "파바바박"의 주력이다. 단단한 것만 있으면 리듬이 죽는다.

### 분열 — 연쇄로 터지는 맛

화물 컨테이너 → 파쇄 패널 3, 함교 잔해 → 폐배선 4, 침몰 격벽 → 파쇄 패널 5.
큰 걸 깨면 또 터지고, 그게 또 파편을 뿌린다.

### 위험물 4종

크레딧이 0이고 **닿으면 특히 아프다.** 지금은 모든 쓰레기가 닿으면 아프므로,
위험물은 "특히" 아픈 것이다. 🟡 역할이 얇아졌다 — 살릴지 뺄지 재검토 필요.

## 2. 무기 — 한 판에 **둘만**, 대신 깊게

rev.4까지는 "5종을 모아 화면을 덮는 것"이었다. rev.5에서 **2개 상한**으로 바꿨다.

| | rev.4 | rev.5 |
|---|---|---|
| 무기 | 5종을 모은다 | **딱 2개** (우주선이 준 것 + 얻은 것) |
| 성장의 증거 | 화면이 덮인다 | 레벨 특성 · 계열 조합 |
| 판마다 다른 것 | 모으는 순서 | **무엇을 골랐나** |

🔴 **무기 12종을 계열 6종에 2개씩 나눴다.**
한 계열에 몰리면 조합 21가지 중 절반이 실제로는 안 나오는 표가 된다.

| 계열 | 무기 | 잘하는 상황 |
|---|---|---|
| 절삭 | 회전 절단날 · 회수 원반 | 포위당했을 때 |
| 관통 | 견인 작살 · 절단 레이저 | 한 방향에서 몰려올 때 |
| 전기 | 정전기 방출 · 충격파 | 잡몹이 많을 때 |
| 폭발 | 압축 폭탄 · 자기 지뢰 | 넓게 퍼져 있을 때 |
| 장판 | 흡입 소용돌이 · 플라즈마 방벽 | 밀집 구간 |
| 중력 | 중력 우물 · 견인 드론 | 흩어진 것을 모을 때 |

### 레벨 특성 — 3 · 5 · 7 · 10

🔴 **레벨업이 "피해 +10%"뿐이면 7레벨이나 3레벨이나 같은 무기다.**
무기를 둘만 갖는 구조라 하나를 10레벨까지 끌고 가는 판이 흔하다.
정해진 레벨에서 **행동이 하나 늘어난다.**

### 조합 21가지 — 무기 쌍이 아니라 **계열 쌍**

무기 12종이면 쌍이 66개다. 계열 6종이면 21가지로 끝나고,
**무기를 20종으로 늘려도 조합표는 그대로**다.

## 3. 카드 17장 (무기 카드는 데이터가 아니다)

🔴 **무기 카드를 데이터로 두지 않는다.** `RunDirector`가 `content.weapons`에서 그때그때 만든다 —
무기를 추가할 때마다 카드도 같이 써야 하면 반드시 어긋난다.

| 분류 | 장수 | 역할 |
|---|---|---|
| (무기) | 자동 생성 | **눈에 보이는 성장** — 다음 특성이 카드에 미리 보인다 |
| 무기 공통 (피해·사거리·쿨다운) | 6 | 빌드 방향 |
| 수집 (흡수·가치·경험치·연료) | 5 | 눈덩이 |
| 생존·기동 (속도·충돌저항·연료) | 6 | 오래 버티기 |

각 분류에 **일반판과 희귀판**을 뒀다 — `출력 증폭 +25%`(가중치 16) vs
`고출력 회로 +45%`(가중치 7). 가끔 좋은 게 뜨는 맛이 있어야 뽑기가 재미있다.

> 🔴 **숫자만 오르는 카드만 있으면 지친다.** "무기가 하나 더 생긴다"처럼
> **화면이 바뀌는 카드**를 꾸준히 섞는다. 무기 카드 가중치를 높게 둔 이유다.

🟡 미정: 카드 중복 등장 규칙, 무기 최대 레벨.

## 4. 웨이브 곡선 — 완만하게 시작한다

실제 뱀서를 찾아본 결과: **웨이브는 1분마다, 동시 300마리를 넘으면 스폰 정지**,
초반 1~2분은 적이 몇 마리씩 띄엄띄엄.

내가 처음 넣은 값은 **시작부터 유입 11/초 · 상한 120**이었고, 그래서 시작부터 덮였다.

```
웨이브 1: 2.5/초 · 25개      ← 무기 하나로 여유롭게
웨이브 3: 5.3/초 · 95개
웨이브 6: 16/초 · 200개      ← 여기가 "파바바박"
```

**"파바바박"은 무기가 쌓인 뒤에 오는 보상**이지 시작 상태가 아니다.

## 5. 영구 성장 (rev.5에서 구현됨)

| 재화 | 획득 | 용도 |
|---|---|---|
| **고철** | 모든 쓰레기 | 얕은 노드를 양으로 |
| **회로** | 티어 1+ | 갈림길을 연다 |
| **코어** | 티어 2 · 보스 | 판을 바꾸는 끝 노드 · 우주선 해금 |

재화를 셋으로 나눈 이유: 하나면 "많이 모으면 다 산다"가 되어 **순서가 사라지고**,
희귀한 것 하나에 전부 묶으면 운에 휘둘린다.

**테크트리 47노드** · **우주선 6척**. 자세한 건 `wiki/meta-progression.md`.

🔴 **우주선은 스탯 묶음이 아니다.** 시작 무기를 정하므로 **조합의 절반을 미리 결정한다.**
그래서 배마다 시작 무기의 계열이 전부 다르다 — 여섯 계열에 하나씩.
스탯도 전부 플러스가 아니라 **맞바꾸기**다. 안 그러면 나중에 해금한 배가 항상 좋아져서 선택이 사라진다.
