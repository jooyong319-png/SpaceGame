# 살비지런 — 외부 리뷰용 설계 요약 (자기완결)

> 🔴🔴 **경고 — 이 요약은 rev.5 시점이다** (2026-08-22 확인).
> rev.7~10에서 축이 여러 번 바뀌었다. **연료 = HP · 적이 몰려온다 · 무기 12종**은 전부 옛 내용이다.
> 외부 리뷰를 부탁할 때 이 파일을 그대로 주면 **없는 게임을 리뷰받게 된다.**

> 이 문서 하나만 읽으면 게임 전체를 알 수 있도록 쓴 것이다. 다른 문서를 참조하지 않는다.
> 다른 AI나 사람에게 검토를 부탁할 때 이 파일을 통째로 준다.
>
> **rev.5 · 2026-08-21** · 개발자 1인 · Unity 6.3 LTS (URP 2D)
> 상태: **컴파일은 되지만 rev.5는 한 번도 플레이되지 않았다.**

---

## 1. 한 줄

**우주를 청소하는 느낌의 뱀파이어 서바이버즈 계열.**

사방에서 몰려드는 우주 쓰레기를 무기가 자동으로 갈아버리고, 나온 파편을 흡수해 성장한다.
적을 죽이는 게 아니라 **잔해를 자원으로 만든다**는 게 표현상의 차이다.

---

## 2. 한 판의 흐름

```
맵 선택 (클리어한 만큼 해금)
   └─ 출항
        웨이브 1 → 2 → … → N          (50초마다, 갈수록 거세짐)
          · 쓰레기가 화면 밖에서 배를 향해 몰려온다
          · 무기가 자동으로 갈아버린다 → 파편이 터진다
          · 파편 흡수 = 크레딧 + 경험치
          · 레벨업 → 카드 3장 중 1장
        마지막 웨이브 → 보스 → 격파하면 맵 클리어 + 다음 맵 해금
        연료 0 → 격침
```

한 판 5~10분. 맵 6종.

---

## 3. 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 홀드 | 커서 쪽으로 추진 (떼면 관성) |
| Shift / 우클릭 | 대시 |
| 커서 위치 | 조준 — 작살이 그쪽으로 날아간다 |

**이동에 비용이 없다.** 도망이 곧 생존이기 때문.

---

## 4. 연료 = HP

쓰레기에 **닿을 때만** 줄어든다. 이동·대시는 무료. 0이면 격침.
접촉은 개체당 0.45초 쿨다운이 있어 스치고 빠지면 한 대만 맞는다.

---

## 5. 무기 — 🔴 한 판에 **딱 2개**

**이게 이 게임이 뱀서와 갈리는 지점이다.**

| | 뱀파이어 서바이버즈 | 살비지런 |
|---|---|---|
| 무기 | 6개까지 **넓게** 모은다 | **2개**를 깊게 판다 |
| 첫 무기 | 캐릭터가 정한다 | 우주선이 정한다 |
| 나머지 | 계속 늘어난다 | **하나만 얻는다** |
| 진화 | 무기 + 패시브 | **두 무기의 계열 조합** (히든) |

무기 **12종**을 계열 6종(절삭·관통·전기·폭발·장판·중력)에 2개씩 나눴다.
전부 자동이고, 플레이어는 위치와 커서 방향만 정한다.

### 레벨 특성 — 3 · 5 · 7 · 10

레벨업이 숫자만 올리면 7레벨이나 3레벨이나 같은 무기다.
정해진 레벨에서 **행동이 하나 늘어난다** (예: 절단날 5레벨 = 톱니 — 내구가 많이 남은 것일수록 더 깎는다).

### 조합 21가지 (히든)

두 무기가 모두 기준 레벨에 닿으면 계열 조합이 열린다.
**무기 쌍이 아니라 계열 쌍**이라 무기를 20종으로 늘려도 조합표는 그대로다.
미리 알려주지 않는다 — 발견이 보상이다.

**카드**: 무기 카드는 데이터가 아니라 무기 목록에서 자동 생성. 패시브 카드 17장.

## 6. 쓰레기 22종 — 이동 패턴으로 구분한다

Chase(추적) · Drift(직진) · Zigzag(사행) · Charger(돌진) · Orbiter(포위)
+ 분열(부서지면 새끼) + 무리(떼로 등장) + 위험물 4종(닿으면 특히 아픔).

잡몹(HP 1, 5마리씩)부터 대형(HP 28)까지.

---

## 7. 웨이브 곡선

| 웨이브 | 유입 | 화면 상한 |
|---|---|---|
| 1 | 2.5/초 | 25 |
| 3 | 5.3/초 | 95 |
| 6 | 16/초 | 200 |

웨이브마다 유입 ×1.45, 상한 +35 (최대 300).
실제 뱀서를 참고했다 — 초반은 한산하고 후반에 급격히 오른다.

---

## 8. 영구 성장 (rev.5에서 구현됨)

죽으면 **재화가 남는다.** rev.4까지 이 게임의 가장 큰 구멍이었다.

| 재화 | 어디서 | 역할 |
|---|---|---|
| 고철 | 모든 쓰레기 | 얕은 노드를 양으로 |
| 회로 | 티어 1+ | 갈림길을 연다 |
| 코어 | 티어 2 · 보스 | 끝 노드 · 우주선 해금 |

- **테크트리 47노드** — 격자 배치, 선행 관계에서 선이 자동 생성된다
- **우주선 6척** — 계열마다 하나씩. 🔴 배가 시작 무기를 정하므로 **조합의 절반을 미리 결정한다**
- 스탯은 전부 플러스가 아니라 **맞바꾸기** (폭파선은 화력 +35%, 대신 연료 -25%에 충돌 피해 증가)

## 9. 개발 상황 (정직하게)

**된 것**
- 위 1~8 전부 코드로 구현되어 있고 **컴파일 통과**
- 절차적 사운드 · 화면 흔들림(F3로 끌 수 있음) · 피격 섬광
- 코드로 찍은 임시 도트 (`PixelArt.cs` — 진짜 아트가 오면 파일 하나 삭제)

**안 된 것 / 문제**
- 🔴 **rev.5를 한 번도 플레이하지 않았다.** 무기 2개 상한·조합·테크트리·우주선이
  하룻밤에 들어갔고 전부 미검증이다
- 🔴 **밸런스 전부 미검증.** 무기 12 × 조합 21은 손으로 못 잰다.
  헤드리스 시뮬레이터가 있었으나 API가 바뀌어 현재 비활성
- 🔴 XP 곡선 미측정 (`xpBase 90 · xpGrowth 1.35`)
- 🟡 조합이 열려도 **화면에서 잘 안 보인다** — 지금은 색만 섞는 임시 처방
- 🟡 마우스 입력이 원격 데스크톱에서 불안정 (실기 확인 필요)
- 보스가 HP 큰 덩어리 4개일 뿐, 방해 행동이 없다
- 도트 담당 미정 — **일정의 최대 변수**

**목표**: itch.io에 WebGL 데모 → 반응 보고 스팀

## 10. 이 프로젝트의 이력 (같은 실수를 다시 제안하지 않도록)

24시간 안에 컨셉이 **네 번** 바뀌었다.

| | 버린 것 | 이유 |
|---|---|---|
| rev.1 | 횡스크롤 · 연료 귀환 도박 | 마우스 조작으로 전환 |
| rev.2 | 지역 선택 · 도구 슬롯 · 화물 무게 | 선형 하강으로 |
| rev.3 | 층 순차 하강 · 환생 · 테크트리 · "깎기" | **재미가 없었다** |
| rev.4 | 뱀서라이크 · 무기 5종을 모은다 | 무기를 넓게 → **깊게**로 |
| rev.5 | (현재) 무기 2개 상한 · 계열 조합 · 영구 성장 | |

**rev.1~3은 한 번도 플레이하지 않은 채 갈아엎었다.** 문서만 2,500줄 나왔다.
그래서 **"플레이 30분 전에는 브리프를 전면 개정하지 않는다"** 는 규칙을 박아 뒀다.

⚠️ **rev.4→5도 플레이 없이 이뤄졌다.** 다만 축(뱀서라이크·청소)은 그대로 두고
그 위의 시스템만 바꾼 것이라 되돌리기가 싸다 — 무기 상한은 설정값 한 줄이다.

### 이미 걸러낸 것 (다시 제안하지 않아도 된다)

- **환생/프레스티지** — 리셋 손실 > 완화 보상이라 아무도 안 누른다
- **테크트리 노드 격자** — 재미 대비 구현비가 최악
- **층 순차 하강 · 하강 선택지** — 뱀서 맵 구조로 대체
- **우주선 증축(모듈 조합)** — 우주선 종류와 역할이 겹치고 구현비가 훨씬 크다
- **거리에 따른 채굴 효율** — 세 번 시도했고 세 번 다 체감이 없었다
- **"전투 0"** — 전투를 빼고는 이 장르가 성립하지 않는다. 대신 **표현만 청소로** 유지
- 멀티플레이 · 스토리 · 컷신 · 3D · 모바일

3. **조합 21가지를 플레이어가 발견할까?** 히든으로 두는 게 맞나, 아니면 도감을 줘야 하나?
4. **우주선 6척이 실제로 다르게 느껴질까?** 시작 무기 + 스탯 맞바꾸기로 충분한가?

   자른다면 어디부터?
