## 0. 한 줄

**우주를 청소하는 느낌의 뱀서라이크.**

사방에서 몰려드는 우주 쓰레기를 무기가 자동으로 갈아버리고, 파편을 흡수해 성장한다.

- 장르: 2D 픽셀아트 · 뱀파이어 서바이버즈 계열
- 플랫폼: PC(Windows) · 웹(WebGL) 데모 · 엔진 **Unity 6.3 LTS (URP 2D)**
- 임시 제목: **SALVAGE RUN / 살비지런** 🟡 공개 전 확정

## 1. 핵심 루프

```
맵 선택 (클리어한 만큼 해금)
   └─ 출항
        웨이브 1 → 2 → … → N          (50초마다, 갈수록 거세짐)
          · 쓰레기가 화면 밖에서 배를 향해 몰려온다
          · 무기가 자동으로 갈아버린다 → 파편이 터진다
          · 파편 흡수 = 크레딧 + 경험치
          · 레벨업 → 카드 3장 중 1장
        마지막 웨이브 → 보스 → 격파하면 **맵 클리어 + 다음 맵 해금**
        연료 0 → 격침
```

한 판: **5~10분** (맵마다 6~12웨이브)

### 🔴 재미가 나오는 지점 (rev.5에서 바뀐 곳)

**"고른 무기 둘이 점점 괴물이 되는 것."**

rev.4까지는 *"무기가 늘어나면서 화면이 덮이는 것"*이라고 적혀 있었다.
rev.5에서 **무기를 2개로 제한하면서 그 그림을 포기했다.**

| | rev.4 | rev.5 |
|---|---|---|
| 무기 | 5종을 모은다 | **딱 2개**를 깊게 판다 |
| 성장의 증거 | 화면이 무기로 덮인다 | 레벨 특성 · 계열 조합 |
| 판마다 다른 것 | 어떤 순서로 모았나 | **무엇을 골랐나** (조합이 갈린다) |

🔴 **이건 도박이다.** 넓게 모으는 쾌감을 버리고 고르는 재미를 택했다.
성립하지 않으면 **상한을 3개로 올리는 것**이 되돌리는 방법이다.

그러므로 **모든 기능은 "두 무기가 자라는 게 보이는가"로 판단한다.**

## 4. 무기 — 한 판에 딱 2개

전부 자동이다. 플레이어는 **위치와 커서 방향**만 정한다.

| | |
|---|---|
| 첫 무기 | **우주선이 정한다** (🟡 우주선 종류 미구현 — 지금은 설정값) |
| 두 번째 | 런 중에 **얻는다.** 그 판의 첫 갈림길이고, 여기서 조합까지 정해진다 |
| 이후 카드 | 그 둘의 강화 + 패시브 |

**무기 12종**, 계열 6종에 2개씩:

| 계열 | 무기 |
|---|---|
| 절삭 | 회전 절단날 · 회수 원반 |
| 관통 | 견인 작살 · 절단 레이저 |
| 전기 | 정전기 방출 · 충격파 |
| 폭발 | 압축 폭탄 · 자기 지뢰 |
| 장판 | 흡입 소용돌이 · 플라즈마 방벽 |
| 중력 | 중력 우물 · 견인 드론 |

### 레벨 특성 — 3 · 5 · 7 · 10

레벨업이 숫자만 올리면 7레벨이나 3레벨이나 같은 무기다.
정해진 레벨에서 **행동이 하나 늘어난다** (예: 절단날 5레벨 = 톱니, 내구가 많이 남은 것일수록 더 깎는다).

### 🔴 조합 21가지 (히든)

두 무기가 모두 기준 레벨에 닿으면 **계열 조합**이 열린다.
무기 쌍이 아니라 **계열 쌍**이라 무기를 늘려도 조합표는 그대로다.

미리 알려주지 않는다 — 발견이 보상이다.

## 4-1. 영구 성장 (rev.5 신규)

죽어도 **재화가 남는다.** 그게 rev.4까지 이 게임의 가장 큰 구멍이었다.

| 재화 | 어디서 | 역할 |
|---|---|---|
| 고철 | 모든 쓰레기 | 얕은 노드를 양으로 |
| 회로 | 티어 1+ | 갈림길을 연다 |
| 코어 | 티어 2 · 보스 | 판을 바꾸는 끝 노드 |

**테크트리 47노드** — 선체 · 기동 · 화력 · 수집 · 무기 · 특수.
가장 비싼 것은 **판이 시작되는 모양**을 바꾸는 노드다 (시작 레벨, 카드 선택지, 조합 요구 -1).

## 5. 쓰레기 — 종류를 가르는 건 이동 패턴이다

**22종.** 숫자만 다르면 종류가 아무리 많아도 한 종류로 느껴진다.

| 패턴 | 성격 |
|---|---|
| **Chase** | 곧장 쫓아온다 |
| **Drift** | 직진만. 피하면 지나간다 |
| **Zigzag** | 사행하며 접근 — 예측이 어렵다 |
| **Charger** | 멈칫했다 돌진 |
| **Orbiter** | 맴돌며 서서히 조인다 |

여기에 **분열**(부서지면 새끼가 나온다)과 **무리**(떼로 나온다)를 얹는다.
위험물 4종은 닿으면 특히 아프다.

## 6. 맵과 웨이브

**맵 하나가 완결된 한 판이다.** 웨이브를 다 넘기고 보스를 잡으면 클리어, 다음 맵이 열린다.
맵 6종 — 기지 궤도 · 폐선 항로 · 잔해장 · 파괴된 정거장 · 심연 · 균열.

**맵은 화면보다 크다.** 카메라가 배를 따라간다 — 도망칠 공간이 없으면 이 장르가 성립하지 않는다.

### 🔴 웨이브 곡선은 완만하게 시작한다

| 웨이브 | 유입 | 화면 상한 |
|---|---|---|
| 1 | 2.5/초 | 25 |
| 3 | 5.3/초 | 95 |
| 6 | 16/초 | 200 |

웨이브마다 유입 ×1.45, 상한 +35 (최대 300 — 뱀서와 같은 값).

**"파바바박"은 무기가 쌓인 뒤에 오는 보상이지 시작 상태가 아니다.**
시작부터 몰아치면 보상이 아니라 벽이 된다.

## 7. 우주선 6척

**계열마다 한 척씩.** 배가 시작 무기를 정하므로 **조합의 절반이 배 선택에서 결정된다** —
우주선을 고르는 것은 "어떤 계열로 갈까"를 고르는 것이다.

| 배 | 시작 무기 | 맞바꾸기 |
|---|---|---|
| 정비선 · 핸디 | 회전 절단날 | 표준. **무료** |
| 포경선 · 하푼 | 견인 작살 | 사거리 ↑ / 연료 ↓ |
| 굴착선 · 그라인더 | 흡입 소용돌이 | 연료 ↑ / 추진 ↓ |
| 폭파선 · 블래스트 | 압축 폭탄 | 화력 ↑↑ / **맞으면 더 아프다** |
| 전기선 · 아크 | 정전기 방출 | 쿨다운 ↓↓ / 화력 ↓ |
| 견인선 · 타이탄 | 중력 우물 | 흡수·크레딧 ↑ / 화력 ↓ |

🔴 **전부 플러스인 배는 없다.** 그러면 나중에 해금한 배가 항상 좋아져서 선택이 사라진다.

🟡 **우주선 증축은 보류.** 우주선 종류와 역할이 겹치고 구현비가 훨씬 크다.

## 8. 차별점

이 장르는 포화 상태다. 우리가 다른 점은 셋뿐이고, 얇아지면 클론이 된다.

| | 뱀서류 | 살비지런 |
|---|---|---|
| 동사 | 적을 **죽인다** | 쓰레기를 **갈아 자원으로 만든다** |
| 그림 | 총·마법·폭발 | 절단날·작살·소용돌이 — **정비소의 그림** |
| 성장 | 무기를 넓게 모은다 | **둘을 깊게 판다 + 계열 조합** |
| 끝 | 없다 | **맵 클리어가 있다** |

🔴 **1순위는 "청소"라는 동사와 촉감이다.** GIF에 담기는 게 그것뿐이고,
itch 유통이 GIF 기반이기 때문이다. "난이도를 직접 고른다" 같은 건 GIF에 안 담긴다.

## 9. 설계 원칙

1. **화면이 덮이는 그림이 상품이다.** 이걸 흐리는 건 넣지 않는다
2. **무기는 자동으로 작동한다.** 조작 부담을 늘려 손맛을 만들지 않는다
3. **이동에 비용을 물리지 않는다.** 도망이 생존이다
4. **곡선은 완만하게 시작한다.** 초반이 한산해야 후반이 보상이 된다
5. **그레이박스 먼저, 도트는 나중**
6. **원칙은 코드로 강제한다.** 밸런스는 `GameContent`/`RunConfig` 에셋 한 곳에만
