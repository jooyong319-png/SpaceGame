## 왜 문서 뿌리를 하나로 합쳤나

`docs/`(기준 문서)와 `wiki/`(작업 지식)로 갈려 있었는데, 2026-08-26에 **장르가 바뀌면서**
(뱀서라이크 → 인크리멘탈 채굴) `docs/`가 통째로 낡았다. 낡은 기준 문서를
"기준"이라고 부르는 상태가 제일 위험하다 — 그래서 뿌리를 `wiki/` 하나로 모았다.
