## 왜 지금은 안 하나 (진단)
1. 기본 상승 봉당 0.1~0.2% → 한 판 1~2%. 같은 돈으로 정비고 칸이 훨씬 이득
2. 내 플레이와 무관 · 속보는 출동 중이라 매매 못 함
3. 증권 계좌 칸(경제 셋째 · 500)이 늦고, 사고 · 기다리고 · 팔기를 따로 챙겨야 함

## 결정
### 1. 할부 계약 사은품
- 새 회사마다 「청소선 할부 계약서」 — 사은품 케슬러 그룹 주식: 케슬러 금융 30 + 청소선 조선 30 (첫 청구서 45 정도)
- 장부는 회사마다 새로 (`S.market` — 파산하면 새 장) → 사은품도 회사마다
- **처음 시작**: 윤 대리 첫 인사(`dlg pro`) 중 「청구서는 열두 장」 뒤에 「그럼 계약서부터. 여기 서명.」 → 계약서 → 마우스로 그어 서명 → 「승인」 도장 → 주식 두 장이 오른쪽 [증권 하러 가기] 탭으로 날아감 · 「새 주식 2」 표시 → 윤 대리 「그건 사은품. 우리 그룹 주식이야. 증권 쪽에서 언제든 팔 수 있어 — 청구서 낼 때 보태든가.」 → 원래 인사 이어서
- **파산 뒤**: 격납고 [출발] → 계약서 「(N대)」 → [서명] 단추 한 번(긋기 없음) → 조종실. 대사 짧게 (「또 왔네. 같은 배, 같은 조건」 · 「우리 주식은 망해도 또 줘. 그게 영업이거든」)
- 종이 · 도장 = 지금 대출 계약서(`SweepHudMoney.Contract`) 재사용

### 2. 관문 공로주
- `SweepSim.GateBroken` 의 돈 보상 `max(runAvg×3, BillAmount×0.3)` → 같은 금액의 관련 종목 주식
- 그 종목에 「항로 개통」 호재 (다음 출동 동안 몇 봉 상승) — 바로 팔면 돈과 같고(수수료 1%) 들고 있으면 더
- 붕괴 순간 「공로주 지급」 카드 + 칩이 증권 탭으로
- 관문 → 종목:
  | 관문 | 항로 | 종목 |
  |---|---|---|
  | 폐우주정거장 | 달 | 달 기지 조합 |
  | 달 착륙선 잔해 | 화성 | 화성 제련소 |
  | 궤도 엘리베이터 | 소행성대 | **소행성 광업 (신규)** |
  | 소행성 채굴기 | 목성 | 목성 선박 |
  | 두 동강 난 화물선 | 토성 | 토성 고리 관광 |
  | 얼음 요새 · 탐사 모선 | 천왕성 · 해왕성 | **심우주 탐사 (신규)** |
  | 폭풍 관측소 · 명왕성 탐사선 | 카이퍼 · 오르트 | 소행성 광업 |
  | 혜성 채굴 기지 · 보이저 탐사선 | 태양권 계면 · 성간 | 심우주 탐사 |
- 신규 두 종목은 해당 항로가 열리면 상장 (그 전엔 목록에 「상장 예정」) · 속보 몇 개 추가

### 3. 증권 화면 · [증권 계좌] 칸
- 증권 화면은 처음부터 열림: 보기 · **매도** · 출동 중 S 시세
- [증권 계좌] 칸(a_open · 500 그대로) = **직접 매수 해금**. 설명: 「직접 매수 해금 — 원하는 종목을 골라 매수」
- 뒤 칸(개미의 기도 · 내부자 정보 · 악재 회피 · 수수료/배당) 그대로
- 한 주임 첫 인사(`dlg stock`) = 증권 화면 처음 열 때 (「사은품 주식 들어와 있네요, 대표님」) · 칸 살 때는 「이제 직접 매수도 되세요」 한 줄
- 칸 사면 증권 방으로 이동 (그대로)
- 청구서 띠에 「주식 매도 시 납부 가능」 표시

## 만들 때 주의
- 봇(`tools/pacing`)은 주식을 안 다룬다 → 공로주는 **받자마자 판다**로 맞춰 난이도 계산 유지
- 사은품도 봇은 바로 판다 (첫 청구서가 쉬워지는지 확인 · 숫자는 사장님 결정)
- UI 글은 명사형 (`salvagerun-ui-tone`)
- 새 화면 = 시안 승인 끝 (위 두 개)
